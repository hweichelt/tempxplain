# Installation

The *tempxplain* system is available in [PyPI](https://pypi.org/project/tempxplain/).
Install it using pip by running the following command in your terminal:

```console
pip install tempxplain
```

-----

A successful installation will make the `tempxplain` command available in your terminal. You can check the installation by running:

```console
tempxplain -h
```

This will display the help message with available options and usage instructions, for detailed CLI information refer to the [CLI documentation](../reference/cli/index.md).
